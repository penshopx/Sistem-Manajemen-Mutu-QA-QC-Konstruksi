Ya, itu jenis informasi API yang saya maksud. Namun, tiga endpoint tersebut punya kegunaan yang berbeda untuk ERP:

Endpoint	Kecocokan
GET /api/v1/catalog/*	Untuk menampilkan produk dan paket Gustafta; bukan integrasi pengetahuan proyek.
POST /api/v1/orders	Untuk pemesanan; tidak diperlukan untuk tahap awal copilot.
POST /api/v1/ai/assist	Calon titik integrasi bantuan AI baca-saja, jika kontraknya mendukung kasus penggunaan dokumen proyek.
Sebelum memakai ai/assist, saya perlu melihat dokumentasi request/response-nya: data apa yang dikirim, apakah hasil menyertakan kutipan dan versi dokumen, bagaimana cakupan proyek/tenant dijaga, serta aturan penyimpanan data, batas pemakaian, dan penanganan kegagalan. Kunci API nantinya hanya boleh digunakan server-ke-server, tidak di browser.
